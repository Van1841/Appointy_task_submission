# 🚀 Quick Installation Guide

## Step 1: Create Icons (1 minute)

1. Open `create-icons.html` in your browser (just double-click it)
2. Click the 3 download buttons to get the icons
3. Save all 3 PNG files in this folder (`synapsemind-extension`)

---

## Step 2: Load Extension in Chrome (1 minute)

1. Open Chrome and go to: `chrome://extensions/`

2. **Turn ON** "Developer mode" (toggle in top-right)

3. Click **"Load unpacked"** button

4. Select this folder:
   ```
   C:\Users\vansh\Favorites\Appointy Task Round\synapsemind-extension
   ```

5. Extension installed! 🎉

---

## Step 3: Pin Extension (optional)

1. Click the **puzzle piece icon** in Chrome toolbar
2. Find "SynapseMind Clipper"
3. Click the **pin icon** to keep it visible

---

## Step 4: Login

1. Click the **🧠 extension icon** in toolbar
2. Enter your SynapseMind email and password
3. Click **Login**

---

## Step 5: Start Saving!

### Try it now:
1. Go to any website (e.g., https://news.ycombinator.com)
2. Select some text
3. Right-click → "💾 Save to SynapseMind"
4. See the notification: "✅ Saved!"
5. Open http://localhost:5173/dashboard to see it!

---

## ⚠️ Important

**Make sure backend is running:**
```bash
cd backend
node server.js
```

Backend must be running on `http://localhost:5000` for the extension to work.

---

## 🎯 Usage Tips

- **Save text:** Select → Right-click → Save
- **Save image:** Right-click on image → Save Image
- **Save link:** Right-click on link → Save Link
- **Save page:** Right-click anywhere → Save Page
- **Keyboard:** Select text → `Ctrl+Shift+S`

---

## ✅ You're Done!

Extension is ready to use. Browse the web and save anything you find interesting!

Check your dashboard to see all saved items organized by AI. 🧠✨
